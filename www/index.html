Panduan (ketuk untuk tutup)

Alat gambar (menu): Pena, Garis, Kotak, Lingkaran (tarik dari titik tengah), Isi area, Pipet (ambil material dari layar), Geser layar. Cubit dua jari untuk zoom, geser dua jari untuk menggeser.

Api membakar kayu, minyak, bensin, arang, tanaman, jamur, mesiu; meledakkan TNT, Gas, Hidrogen, Nitro, Kembang Api
Air + Natrium = ledakan; + Semen = Beton; + Tanah = Lumpur; + Benih/Tanaman = tumbuh; + Mesiu = basah
Lava + Air = Batu dan Uap; + Es = Obsidian; melelehkan batu dan logam; memanggang tanah jadi batu
Nitrogen membekukan air dan tanaman, menguap kena api/lava
Uranium memancarkan api dan memanaskan air jadi uap
Asam melarutkan batu, kayu, logam, beton; + Natrium/Nitro = ledakan
Jamur menyebar di kayu, tanaman, tanah, lumpur; mati kena garam/asam
Logam + Air lama-lama berkarat; Lumpur + Api = Tanah; Salju + Garam = Air
Keran: Air, Lava, Asam, Minyak; Void menghapus semuanya
