# Sandbox Serbuk
1. Upload semua isi folder ini (termasuk .github dan debug.keystore) ke repo GitHub, branch main.
2. Settings > Actions > General > Workflow permissions: pilih "Read and write permissions" (jika release gagal).
3. Setiap push akan build APK dan membuat Release otomatis (tab Releases di repo).
4. Unduh APK dari Releases lalu pasang di HP.
